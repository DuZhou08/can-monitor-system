## 系统组成

- **主机**（STM32F407VET6）：ILI9341 320×240 TFT + HR2046 触摸（SPI2）、W25Q64 Flash（SPI1）、TJA1050
- **从机 0**（STM32F103C8T6）：光敏模块 + 热敏模块（ADC）、OLED（I2C）、TJA1050
- **从机 1**（STM32F103C8T6）：MPU6050（I2C）、OLED（I2C）、TJA1050
- 三节点经 **CAN 总线（125 kbps · 双绞 · 两端 120 Ω · 共地）** 互联

## 接线

### CAN 总线
| 项     | 说明                                                     |
| ------ | -------------------------------------------------------- |
| 速率   | 125 kbps (PSC 主机 56 / 从机 48)                         |
| 引脚   | PA11 = CAN_RX → TJA1050 RXD；PA12 = CAN_TX → TJA1050 TXD |
| 收发器 | TJA1050，VCC = 5V                                        |
| 终端   | 总线**两端**各 120 Ω                                     |
| 连线   | CANH / CANL **双绞**，三节点**共地**                     |

### 主机接线
| 外设          | 信号                   | 引脚                   |
| ------------- | ---------------------- | ---------------------- |
| ILI9341       | SCK / MOSI / MISO      | PB13 / PB15 / PB14     |
| ILI9341       | CS / DC / BKL / RST    | PB12 / PC5 / PB1 / PB0 |
| HR2046 (触摸) | CS / IRQ               | PC6 / PC7              |
| W25Q64        | CS / SCK / MISO / MOSI | PA4 / PA5 / PA6 / PA7  |
| TJA1050       | RXD / TXD              | PA11 / PA12            |
| 工作灯        | LED1                   | PA1                    |

### 从机 0 (slave-sensors) 接线

| 光敏模块 | AO        | PA0 (ADC1_IN0) |

## 电源
- 三节点统一 **5V** 供电、**共地**
- **TJA1050 必须 5V**（3.3V 会导致从机掉线）
- 各开发板/MCU 用板载 LDO 转 3.3V

## 已知问题 / 备注
- **终端电阻**：模块板载 120 Ω，三节点实测为 **3×120 Ω = 40 Ω**（过终端）。总线 <1m、125 kbps 下可接受；规范做法是仅**两端**各 120 Ω。
- **TJA1050 供电**：早期 3.3V 供电导致从机频繁掉线；统一 **5V** 后 `ERR T/R = 0/0`。
- **温度标定**：NTC 为单点实测标定（26°C ↔ ADC 1750），非线性误差见 `PROTOCOL.md`。
