# CAN 通信协议

> v1.0 · 2026-10 · DuZhou

三节点总线：STM32F407 主机 + 2× STM32F103 从机，**125 kbps 标准帧**。

**简体中文** | [English](PROTOCOL.en.md)

## 节点与地址

| 节点   | 工程            | 地址   | 职责               |
| ------ | --------------- | ------ | ------------------ |
| 主机   | `master`        | —      | 汇聚 / 显示 / 命令 |
| 从机 0 | `slave-sensors` | `0x00` | 光照 / 温度        |
| 从机 1 | `slave-mpu`     | `0x01` | MPU6050 姿态       |

## 总线

- 125 kbps：PSC 主机 56（42M）/ 从机 48（36M）
- 位时序 1 + 2 + 3 = 6tq，采样点 50%，SJW 2tq
- 收发器 TJA1050 **5V 供电**，两端 120Ω，三节点共地
- 引脚 PA11 RX / PA12 TX

## 报文（多字节一律大端）

| ID              | 方向                 | 帧内容                              | DLC   |
| --------------- | -------------------- | ----------------------------------- | ----- |
| `0x300`         | slave-sensors → 主机 | `光照u16` `温度u16` `序号u8`        | 5     |
| `0x301`         | slave-mpu → 主机     | `AX i16` `AY i16` `状态u8` `序号u8` | 6     |
| `0x310` `0x311` | 从机 → 主机          | `指令u8` `结果u8` `TEC u8` `REC u8` | 4     |
| `0x500`         | 主机 → 从机          | `目标u8` `指令u8` `参数u16`         | 2 / 4 |

- 从机地址 = `ID & 0xFF`
- 温度换算：`0.1°C = raw × 260 / 1750`
- 状态：`0`=正常，`1`=MPU6050 异常
- 命令码：`0x01` SET_PERIOD（参数 = 周期 ms，20~1000）｜ `0x02` PING

## 机制

- **丢帧**：主机按帧序号差值统计，离线 >2s 后重新对齐
- **断线**：>2s 未收到帧 → 判离线
- **接收过滤**：主机收 0x300 / 0x301 / 0x310 / 0x311；从机收 0x500（精确匹配，ID 左移 5）
- **错误诊断**：读 `CAN1->ESR` → `REC[31:24]` `TEC[23:16]` `LEC[6:4]` `BOFF/EPVF/EWGF[2:0]`

## 附录：LEC 错误码

0 无 · 1 填充 · 2 格式 · 3 应答 · 4 隐性位 · 5 显性位 · 6 CRC · 7 软件
